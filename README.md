# 롤토체스 최적 조합 탐색기

원하는 상징(엠블럼)을 입력하면 그 상징을 가장 잘 살리는 기물 조합을 찾아 주는 웹 도구입니다.
서버 없이 브라우저에서만 돌아가므로 GitHub Pages에 그대로 올려 쓸 수 있습니다.

원본은 터미널에서 돌아가던 파이썬 스크립트 두 개였고, 그 탐색 알고리즘을 결과가 완전히 동일하도록
자바스크립트로 옮긴 뒤 웹 화면을 붙였습니다.

## 두 가지 탐색 방식

- **상징 특화** — 입력한 상징의 시너지 레벨을 최대한 높입니다. 예를 들어 "거리의 악마" 상징 1개를 넣으면,
  거리의 악마 시너지 단계를 가장 높이 올리는 8기물을 찾아 줍니다. 상징을 하나 이상 넣어야 합니다.
- **유연함** — 활성화되는 시너지 "종류 수"를 최대로 늘립니다. 여러 시너지를 동시에 켜는 다양성 위주 조합을
  찾습니다. 이때 바이러스·영혼 살해자·군주·네트워크의 신은 종류 수 계산에서 제외합니다.
  상징 입력은 선택 사항이며, 넣으면 그 상징을 반드시 포함한 채로 탐색합니다.

## 사용법

1. 탐색 방식을 고릅니다.
2. 상징과 개수를 입력합니다. 상징이 여러 개면 "상징 추가"로 행을 늘립니다.
3. 배치 기물 수(기본 8)를 확인하고 "최적 조합 찾기"를 누릅니다.
4. 결과로 챔피언 목록, 활성 시너지, 어떤 챔피언이 어떤 상징을 드는지(상징 배치)가 나옵니다.

무거운 탐색은 웹 워커에서 돌리므로 계산 중에도 화면이 멈추지 않습니다.

## 로컬에서 실행하기

웹 워커는 `file://`로 직접 열면 브라우저 보안 정책에 막힐 수 있습니다. 로컬에서 볼 때는 간단한 서버를 띄우세요.

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

(워커가 막히는 환경에서는 자동으로 메인 스레드 계산으로 넘어가므로 동작 자체는 됩니다. 다만 무거운
입력에서는 화면이 잠깐 멈출 수 있습니다.)

## GitHub Pages 배포

1. 이 폴더의 파일을 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치, 폴더를 `/root`(또는 파일을 넣어 둔 경로)로 지정합니다.
3. 잠시 후 발급되는 `https://<계정>.github.io/<저장소>/` 주소로 접속하면 됩니다.

정적 파일만으로 동작하므로 별도 빌드 과정은 없습니다.

## 알고리즘 요약

- **상징 특화**는 목표 시너지 단계별로, 해당 특성을 원래 가진 기물(코어) 조합 → 상징을 들 기물 조합 →
  나머지 칸을 점수가 가장 높아지도록 채우는 그리디 탐색을 돌려 최고 점수 조합을 고릅니다. 입력 상징에
  가중치를 크게 주어 그 시너지를 우선합니다.
- **유연함**은 상징이 없으면 그리디로 조합을 만든 뒤 자리 교체(지역 탐색)로 다듬고, 상징이 있으면 상징을
  들 기물 조합마다 그리디로 채워 활성 시너지 종류가 가장 많은 조합을 고릅니다.
- 원본 파이썬의 점수 계산 방식을 그대로 옮겨, 기존 터미널 도구와 결과가 정확히 일치합니다. 탐색의 병목이던
  그리디 채우기 단계는 점수를 증분(delta)으로만 다시 계산하도록 바꿔 속도를 크게 높였고, 최종적으로 기록되는
  조합의 점수는 원본과 동일한 함수로 확정하므로 결과는 달라지지 않습니다.

## 데이터 수정 (세트 교체)

챔피언과 특성 데이터는 모두 `data.js` 한 파일에 있습니다. 세트가 바뀌면 이 파일의 `CHAMPIONS`(챔피언별
특성·코스트)와 `TRAITS`(특성별 브레이크포인트)만 고치면 나머지는 그대로 동작합니다. 현재 데이터는
시즌 14(사이버 시티) 기준입니다.

## 파일 구성

```
index.html    화면 구조
styles.css    스타일
app.js        입력 폼 · 결과 렌더링 · 워커 연결
worker.js     웹 워커 (탐색을 메인 스레드 밖에서 실행)
solver.js     탐색 엔진 (두 방식 모두 포함)
data.js       챔피언 / 특성 데이터
```
